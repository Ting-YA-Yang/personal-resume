## Overview

EasyFin uses Excel as a core business surface for finance configuration, supporting online editing, import validation, approvals, versioning, and audit history.

## Contributions

- Built Case Study APIs for scenarios, accounts, journals, parameter bindings, drafts, and editing-matrix workflows.
- Implemented requirement ingestion and cross-scenario search indexing across DAO, service, resource, DTO, and OpenAPI layers.
- Added the Bank Account List configuration type end to end, including Excel rules, OpenAPI, and automation tests.
