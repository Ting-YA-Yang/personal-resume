## Overview

FX Console is a React-based fund management platform built with a separated frontend and backend, focused on readable financial data and efficient operations.

## Contributions

- Owned the Next.js/TypeScript architecture from 0 to 1, including dynamic routes, SSR, and static generation.
- Used ECharts for fund-flow and trend visualizations, with Ant Design for fast product delivery.
- Improved build and React rendering performance through code splitting, tree-shaking, caching, lazy loading, and memoization.
