## Context

This site brings professional experience, selected projects, and ongoing writing into one focused home while remaining light enough to host on GitHub Pages at no cost.

## Design principles

- Put content first and let typography do the visual work.
- Ship static HTML by default, adding JavaScript only where interaction earns its place.
- Give Chinese and English content separate URLs for sharing, indexing, and maintenance.

## Technical decisions

Astro handles pages and builds, TypeScript keeps content contracts dependable, and MDX makes case studies easy to write. Native CSS defines the visual system and responsive behavior, while React is reserved for small interactive islands.
