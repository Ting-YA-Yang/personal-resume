## Overview

ServicesCentral gives tenant organizations and merchant operators one portal for Payments, Payouts, transactions, balances, reports, API credentials, and disputes.

## Contributions

- Took the product from 0 to 1, improving search, filtering, date validation, and reusable query behavior.
- Contributed to dispute workflows, evidence form state, failed response handling, and clear user feedback.
- Improved responsive layouts for Payment, Payout, and Dispute detail pages, with Vitest, React Testing Library, and Playwright coverage.
- Contributed to CSRF tokens, audit logs, idempotent requests, and DAST test compatibility.
