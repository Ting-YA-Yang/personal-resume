## 项目概述

负责开发基于 React 技术栈的资金管理平台，采用前后端分离模式，通过数据可视化和性能优化提升资金运营体验。

## 主要工作

- 从 0 到 1 完成 Next.js/TypeScript 项目架构、动态路由、SSR 与静态生成能力建设。
- 使用 ECharts 展示资金流向和趋势分析，结合 Ant Design 快速构建业务界面。
- 通过代码分割、Tree-shaking、缓存、懒加载与 Memoization 优化构建和 React 渲染性能。
