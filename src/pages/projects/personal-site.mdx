## 背景

这个网站用于集中呈现职业经历、代表项目与持续写作，同时保持足够轻量，能够免费托管在 GitHub Pages。

## 设计原则

- 内容优先，以清晰的排版代替不必要的装饰。
- 默认输出静态 HTML，只在主题切换等必要位置加载 JavaScript。
- 中文与英文使用独立地址，方便分享、索引与后续维护。

## 技术决策

Astro 负责页面与构建，TypeScript 提供可靠的内容约束，MDX 用来编写项目案例。原生 CSS 定义视觉系统和响应式布局，React 只作为局部交互岛使用。
