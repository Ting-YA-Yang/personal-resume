## 项目概述

面向租户组织和商户运营人员的支付服务管理门户，整合 Payments 后端服务，覆盖支付、Payout、交易、账户余额、报表、API Credentials 与 Dispute 等能力。

## 主要工作

- 从 0 到 1 推进项目开发与上线，完善搜索、筛选、日期校验和跨模块复用能力。
- 参与 Dispute 业务迭代，完善证据表单状态管理、响应提交失败处理与用户反馈。
- 优化 Payment、Payout 和 Dispute 详情页响应式布局，并补充 Vitest、React Testing Library 与 Playwright 测试。
- 参与 CSRF Token、审计日志、请求幂等和 DAST 安全测试适配。
